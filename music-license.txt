BLUE HAVEN (deep sea) — music license note
===========================================
All music and sound in BLUE HAVEN is generated procedurally at runtime by this
project's own code (js/audio.js) using the Web Audio API:
  - very slow, low deep-sea pads (original 4-chord progression, D dorian/lydian colours)
  - sparse, low bell / chime notes, partly randomised
  - distant whale-like calls (gliding sine tones through a band filter), synthesised in code
  - abyssal hush (filtered brown noise) and occasional bubble sounds
  - game sounds: light-orb chimes, feeding bubbles, unlock arpeggio
No audio files, samples, recordings, loops, or third-party / famous melodies are used.
Created by the project for MOTOR AA. Free to use with the game.
