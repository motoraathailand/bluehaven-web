# BLUE HAVEN — first sample

A calm deep-sea healing game for the web (three.js r170, vendored). Play gentle minigames,
gather pearls, and invite new sea life and decorations into your own sea. Progress is saved
in the browser (localStorage).

- Open: `index.html` (static, no build). Low-quality mode: `?q=low`. Demo with everything unlocked: `?demo`.
- All 3D models are built procedurally in code; no external models or textures.
- Music: generated live in code (see `music-license.txt`).
- Languages: th / en / ko / zh / hi.
